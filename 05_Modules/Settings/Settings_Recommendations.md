# Settings Recommendations

Keep the module inactive and retain the two compatibility values until the Intraday satellite migration is complete. Do not add an editor: the active product has no Settings workflow, and exposing controls for a hidden module would add maintenance without helping the six-module investment workflow.

When Intraday is migrated, decide explicitly whether its settings and historical data move with it. Only then remove this shell and the two compatibility keys, with backup migration tests first.
